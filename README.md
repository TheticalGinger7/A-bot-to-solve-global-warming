# A bot to solve global warming
>Данный бот создан для того, чтобы осветить проблему глобального потепления и рассказать о том, как её можно решить. В боте команды для высвечивания информации о том, что такое глобальное потепление, как человечеству начать
>решать данную проблему и как конкретно ты можешь повлиять на это.
>
>команды:
>
>/start Здравствуй человек, это бот который поможет разобраться в проблеме глобального потепления и расскажет про пути её решения напишите
>
>/info чтобы узнать, что такое глобальное потепление
>
>/people чтобы узнать, как человечество может решить проблему глобального потепления
>
>/you чтобы узнать, как конкретно ты можешь поспособствовать решению проблемы глобального потепления.
